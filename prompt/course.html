6교시

TCP/IP 4계층과 통신 흐름

🧱 계층으로 나누는 이유

네트워크 통신은 매우 복잡한 과정입니다. 이를 역할별로 나누어 각 계층이 자기 할 일만 책임지게 하면, 문제가 생겼을 때 원인을 빠르게 좁혀갈 수 있고 계층별로 기술을 독립적으로 교체할 수도 있습니다.

🪜 TCP/IP 4계층 구조

4. 애플리케이션 계층 사람이 사용하는 서비스 규약 — HTTP, HTTPS, DNS, FTP, SMTP 등
3. 전송 계층 데이터를 어떤 방식으로, 몇 번 포트로 주고받을지 결정 — TCP(신뢰성), UDP(속도)
2. 인터넷 계층 출발지에서 목적지까지 경로를 찾아 전달 — IP 주소, 라우팅
1. 네트워크 인터페이스 계층 실제 물리적인 전송 — 이더넷 케이블, Wi-Fi, MAC 주소

🔄 통신 흐름 예시 — 브라우저 주소창에 URL을 입력하면?

  1. 브라우저가 URL에서 도메인을 추출하고, DNS에 질의하여 IP 주소를 얻습니다.
  2. 전송 계층에서 TCP 연결을 맺기 위해 3-way handshake를 수행합니다.
  3. 인터넷 계층이 IP 주소를 바탕으로 여러 라우터를 거쳐 목적지까지 경로를 찾아갑니다.
  4. 애플리케이션 계층에서 HTTP 요청 메시지를 만들어 서버로 전송합니다.
  5. 서버가 응답을 만들어 같은 경로를 거쳐 되돌려 보내고, 브라우저가 화면을 렌더링합니다.
6교시

IP, DNS, Port 개념

🌐 IP (Internet Protocol) 주소

네트워크에 연결된 장치를 식별하는 고유한 주소입니다.

구분형식예시
IPv48비트 × 4자리 (0~255)192.168.0.1
IPv616비트 × 8자리 (16진수)2001:0db8::1

📖 DNS (Domain Name System)

사람이 외우기 쉬운 도메인 이름(www.example.com)을 실제 통신에 필요한 IP 주소로 변환해주는 “인터넷의 전화번호부”입니다.

// 개념적인 흐름 www.example.com --DNS 조회--> 93.184.216.34

🔌 Port (포트)

하나의 IP 주소를 가진 컴퓨터 안에서 어떤 프로그램(서비스)과 통신할지 구분하는 번호입니다. IP가 “건물 주소”라면 Port는 “몇 호실”인지를 나타냅니다.

포트 번호서비스
80HTTP
443HTTPS
22SSH
3306MySQL
6교시

HTTP / HTTPS 개념

📨 HTTP (HyperText Transfer Protocol)

웹 브라우저와 서버가 문서(HTML, JSON, 이미지 등)를 주고받기 위한 약속(프로토콜)입니다.

🔒 HTTPS — HTTP + 암호화

HTTP 통신 내용을 TLS/SSL로 암호화하여 중간에서 누군가 엿보거나 위조할 수 없도록 만든 버전입니다. 기본 포트가 80 → 443으로 바뀌고, 주소창에 자물쇠 아이콘이 표시됩니다.

7교시

HTTP 요청 / 응답 구조

📤 요청(Request)과 📥 응답(Response)

HTTP 통신은 언제나 클라이언트의 요청으로 시작해서 서버의 응답으로 끝나는 1:1 대화 구조입니다.

Request

GET /course.html HTTP/1.1 Host: localhost:8080 User-Agent: Mozilla/5.0 Accept: text/html

Response

HTTP/1.1 200 OK Content-Type: text/html Content-Length: 512 <html>...</html>

🧩 자주 쓰는 HTTP 메서드

메서드의미
GET리소스 조회
POST리소스 생성
PUT리소스 전체 수정
DELETE리소스 삭제

🚦 상태 코드(Status Code)

2xx성공 (200 OK)
3xx리다이렉션 (301, 302)
4xx클라이언트 오류 (404 Not Found)
5xx서버 오류 (500 Internal Error)
7교시 · 실습

간단한 웹서버 작성 및 테스트

🛠️ Node.js로 만드는 최소 웹서버

이 폴더의 index.html, course.html을 서비스하는 서버를 직접 작성해봅니다.

// server.js const http = require('http'); const fs = require('fs'); const path = require('path'); const server = http.createServer((req, res) => { const file = req.url === '/' ? 'index.html' : req.url.slice(1); const filePath = path.join(__dirname, file); fs.readFile(filePath, (err, data) => { if (err) { res.writeHead(404, { 'Content-Type': 'text/plain' }); res.end('404 Not Found'); return; } res.writeHead(200, { 'Content-Type': 'text/html' }); res.end(data); }); }); server.listen(8080, () => { console.log('서버 실행: http://localhost:8080'); });

▶️ 실행 및 테스트 방법

  1. 터미널에서 node server.js로 서버를 실행합니다.
  2. 브라우저에서 http://localhost:8080 접속 → index.html 확인.
  3. http://localhost:8080/course.html로 접속하여 다른 페이지도 확인.
  4. 개발자 도구(F12) → Network 탭에서 실제 요청/응답 헤더와 상태 코드를 직접 관찰해봅니다.
  5. 존재하지 않는 경로(예: /none.html)에 접속해 404 응답을 확인합니다.
